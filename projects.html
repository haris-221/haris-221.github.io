Password Strength Checker

A Python password strength estimator inspired by zxcvbn. Instead of just checking length and character types, it estimates how many guesses an attacker would need.

It finds common words (from a 10,001-word list), years, keyboard patterns and repeated characters, gives each a fixed cost in bits, and treats whatever's left as random. That gives a 0–4 score, crack times for online and offline attackers, and feedback pointing at the weak part. For example, monkey1998 looks like 51.7 bits but drops to 23.3 once monkey1 is spotted.

Split into modules (patterns, maths, display) with 49 pytest tests and a Bandit security scan in GitHub Actions. Known limits: it misses leetspeak like P@ssw0rd1!, uses greedy matching, and scores short random passwords too generously for offline attacks.
